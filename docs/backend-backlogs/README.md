# Backend Module Backlogs

This folder contains per-module backend backlogs for the CoESCD platform.

Status labels:
- `P0`: launch-blocking or high-risk production work
- `P1`: important stabilization or completeness work
- `P2`: medium-priority hardening or expansion
- `Deferred`: intentionally postponed
